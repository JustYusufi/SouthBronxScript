## 🌟 Features

*   **⚡ Real-Time ESP**: Highlights custom characters through walls with neon wireframe boxes and live status overlays.
*   **❤️ Dynamic Name & Health Tags**: Instantly tracks target identifiers and health values (`Name | Health`) floating directly above characters.
*   **🧱 Environment No-Clip Toggle**: Selectively phases out environment objects (walls, props, ceilings) while keeping essential floors solid so you never fall out of bounds.
*   **🎯 Smart Auto-Lock System**: Features an active Field-of-View (FOV) targeting circle and right-click snap-on functionality to lock your view onto the nearest target's head.

---

## 🎮 Controls

| Key | Action | Description |
| :---: | :--- | :--- |
| **`P`** | **Toggle ESP** | Enables or disables character highlights and name/health tags. |
| **`Z`** | **Toggle No-Clip** | Toggles collision off/on for surrounding environment elements. |
| **`,`** | **Toggle TP-Walk** | Enables or disables TP-Walk. |
| **`[`** | **Toggle Auto-Lock** | Enables or disables Auto-Lock. |
| **`Right Mouse Button`** | **Auto-Lock** | Hold down to activate the FOV targeting circle and snap your camera to the closest threat. |
